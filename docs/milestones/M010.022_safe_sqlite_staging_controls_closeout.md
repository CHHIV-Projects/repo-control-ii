## 4. Architecture / Integration Notes

- The persistent freeze marker is stored beneath the file-backed state root's private lock directory. Mutation-aware lock acquisitions check it while holding the existing cross-process lock; read-only lock users remain available.
- The source and candidate roots are distinct. Import copies each source selection byte-for-byte into the candidate root; binding mutates only the candidate copy. `store-authority preview`, `activate`, and `abort` accept `--source-state-root` to recheck the original frozen sources while candidate authority metadata stays in the candidate root.
- Candidate browser and Coder CLI processes must pass the candidate state root explicitly. Their environment must also provide an explicit candidate-only recovery-point path; missing or live-default coverage configuration is rejected for a non-default managed state root.
