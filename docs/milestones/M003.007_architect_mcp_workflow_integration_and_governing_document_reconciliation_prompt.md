# 1. Purpose

M003.004–M003.006 established a complete read-only Architect access path:

```text
ChatGPT / Architect
        ↓
custom MCP app
        ↓
OpenAI Secure MCP Tunnel
        ↓
tunnel-client on henderson-server1
        ↓
repoctl mcp-architect
        ↓
Repo Control /api/architect/v1
        ↓
current repository / milestone / workflow / Git evidence
```

M003.007 must now make that path part of the **normal Repo Control workflow** and reconcile the governing documents so they describe the system that now actually exists.

This milestone is not about adding more MCP transport machinery.

The objective is to make the accepted MCP connection the normal Architect evidence path and remove stale governing-document language that still treats Architect access and Workflow Orchestration as future concepts.

# 20. Lifecycle Hygiene

Preserve the accepted lifecycle:

```text
PLANNING
→ READY
→ IN_PROGRESS
→ WAITING
→ IN_PROGRESS
→ REVIEW
→ IN_PROGRESS (bounded correction)
→ REVIEW
→ CLOSED
```

Do not infer phase from prompt presence, closeout presence, Git status, test results, or commit state.

MCP reports lifecycle; it does not determine lifecycle.

---

```text
Git state and workflow lifecycle are related operationally

```

Git disposition may be recorded, but lifecycle remains event-driven.
