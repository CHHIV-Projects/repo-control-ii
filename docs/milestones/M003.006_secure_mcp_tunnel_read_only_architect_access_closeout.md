## 7. Input Validation

- **Arbitrary Inputs Prohibited**: Tools reject arbitrary URLs, HTTP methods, filesystem paths, shell commands, and Git operations.
- **Strict Schema Enforcement**: All tool schemas declare `"additionalProperties": false`. Any unexpected argument is rejected with code `-32602` or `validation_error`.
- **Preconditions**:
  - `expected_repository_key`: String, non-empty, max 64 characters.
  - `expected_generation`: Non-negative integer.
  - `expected_milestone_id`: String, non-empty, max 32 characters.
- **Document Role Allowlist**:
  - `repo_document` strictly validates that `role` is one of: `{"context", "architecture", "workflow", "coding_agent_rules", "parking_lot"}`. Unknown roles are rejected before any upstream HTTP request.

## 8. Tunnel Runtime

- **Supervision**: Deployed and active as a dedicated systemd service unit: `repo-control-architect-tunnel.service`.
- **Service Independence**:
  - `repo-control.service` and `repo-control-architect-tunnel.service` are separate units.
  - Failure or restart of the tunnel service does not interrupt local Repo Control operation or human SSH access.
  - `repo-control.service` failure cleanly causes the tunnel adapter to report `503 upstream_unavailable` without crashing `tunnel-client`.
- **Restart Policy**: `Restart=on-failure`, `RestartSec=5`.
- **Security Flags**: `NoNewPrivileges=true`, `PrivateTmp=true`.
- **Operational Verification**: Active persistent daemon loading credentials from `/home/chuck/.config/repo-control/tunnel.env` (permissions `0600`), successfully providing the loopback health check at `http://127.0.0.1:8080/readyz`.

## 15. Known Limitations

- **Single Repository Selection**: Like the M003.004 Architect API, the MCP adapter operates against whichever repository is currently active in Repo Control. It cannot switch repositories remotely (by design, keeping access read-only and unprivileged).
- **Selection Pointer**: Milestone selection is read from the local Repo Control external pointer file. If a new milestone is selected in the local web UI, the Architect MCP tools immediately reflect that change on next query.
