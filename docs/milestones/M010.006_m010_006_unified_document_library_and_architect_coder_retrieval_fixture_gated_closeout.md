## 8. Known Limitations

- The library fully enumerates and reads provider records for each search/get operation. The 560-record fixture required about 31 KB of provider content per search and about 0.46 seconds for the measured search-plus-exact-read pair. Larger-volume optimization may be warranted after representative rehearsal; there is no candidate cap or false-complete fallback.
- Git revisions represent labeled, hash-bound current working-tree content, not historical committed Git blobs.
- Export does not retrieve or bundle local attachments; the manifest response discloses this.
- No live Architect/Coder, browser, CLI, or MCP integration is active. The current SQLite runtime remains ineligible for production.
