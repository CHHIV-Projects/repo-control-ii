The existing lifecycle reducer remains the source of the six phases and 21
event types. Managed writes and receipts are transactional. Configuration,
selection, prompt revision/hash, database identity and registry changes are
checked; stale or partially switched clients fail explicitly. Independent
Git-owned source and procedure operations are not dual-written into SQLite.

An uncommitted materialized prompt is allowed only with an exact selected,
approved revision and matching bytes, using the explicit verification option.
Staged, conflicted, hash-mismatched or unrelated dirty paths fail the existing
preflight. The proposed, **unpublished** shared-procedure delta and separate
PO Apply/Recover plan are in the [runtime/operator report](../reports/M010.010_sqlite_runtime_candidate_and_operator_verification.md).
