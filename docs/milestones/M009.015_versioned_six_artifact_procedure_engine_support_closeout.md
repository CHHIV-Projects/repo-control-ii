# Milestone M009.015 — Versioned Six-Artifact Procedure Engine Support

## 1. Scope Completed

Added narrowly allowlisted support for an optional root `AGENTS.md` artifact
in future shared-procedure releases, while preserving the published 1.3.0
five-artifact contract. Both native host bootstrap files render from the
canonical `bootstrap.md` source. Existing root `AGENTS.md` files without
matching procedure-lock provenance are protected collisions.

M009.014 remains paused in `WAITING`. No 1.4.0 release was published, and no
procedure was applied to a live managed repository.

## 2. Resulting Behavior

- Manifest validation accepts the original exact five-artifact mapping or
  that mapping plus root `AGENTS.md`; the sixth artifact must use
  `bootstrap.md` with the bootstrap renderer and a numeric release newer than
  1.3.0. Other target paths and duplicate source mappings remain rejected.
- Rendering, status/integrity inspection, preview, locks, and transaction
  plans include the optional sixth artifact when present.
- A pre-existing `AGENTS.md` lacking matching lock provenance blocks preview
  even when its bytes match the generated bootstrap. Symlink and changed-
  after-review targets fail closed.
- New journals may contain either the exact legacy five-target set or the
  exact six-target set, always followed by the shared-procedure lock. Recovery
  restores recorded before-images and accepts existing five-target journals.
- The browser Review Apply / separate Confirm Apply flow handles the exact
  future six-target plan without changing its confirmation or repository-
  selection safeguards.

## 4. Architecture / Integration Notes

`load_bundle` retains the exact 1.3.0 mapping and recognizes only the optional
fixed root target `AGENTS.md` for a later numeric release. The generated
bootstrap bytes, including release and overlay substitutions, are identical
for `AGENTS.md` and `.github/copilot-instructions.md`. Transaction target
paths and journal validation use explicit five- and six-target allowlists;
the existing exact-image journal and confirmation machinery covers either
set.
