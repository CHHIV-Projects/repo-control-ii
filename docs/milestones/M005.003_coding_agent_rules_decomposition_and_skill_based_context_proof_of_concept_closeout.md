## 2. Resulting Behavior

### 2.1 Always-loaded bootstrap and handoff contract

The reduced bootstrap retains these before any Skill is selected:

- rule priority, Product Owner authority, active prompt and approved lock-in authority;
- authoritative `coder-context`, lifecycle authorization, read-only branch/status/history preflight, and stop conditions;
- the mandatory pre-work feedback rule;
- absolute Coder no-Git authority, project isolation, secrets protection, deterministic evidence, and bounded `coder-question` handling;
- explicit Skill routing, the rule that Skills confer no authority, and safe fallback when a Skill cannot load.

The normal notification may now be only **“Prompt ready.”**, **“Correction ready.”**, or **“Instruction ready.”** The Coder then retrieves current authoritative context, checks repository/branch/lifecycle/scope and approved guidance, applies the pre-work rule, and loads the relevant Skill. The notification itself grants no authority. No standing procedural boilerplate needs to be repeated by the Product Owner.
