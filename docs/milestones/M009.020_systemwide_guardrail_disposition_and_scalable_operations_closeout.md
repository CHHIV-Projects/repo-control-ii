## 2. Resulting Behavior

- Git Review supports up to 5,000 explicitly selected paths and 1 MiB of
  aggregate path bytes, with execution batches bounded to 256 paths/32 KiB.
  Staging is non-atomic, and partial failures report completed batches.
- Review presents the complete bounded staged inventory and a
  snapshot-bound diff with size/hash metadata before a separately confirmed
  commit. Rename-like relocations are represented as deletion/addition paths.
- Selected-milestone document reads return pages of at most 128,000 bytes
  from approved files up to 5,000,000 bytes. Responses include deterministic
  byte offsets, line ranges, completion state, whole-source SHA-256, and a
  continuation fingerprint bound to the path, content, and source snapshot.
- Continuation rejects source changes, including replacement with identical
  bytes but a different source snapshot. Reads preserve UTF-8 boundaries,
  active-prompt path approval, selected-milestone confinement, no-follow
  checks, supported-type restrictions, and private-key rejection.
- HTTP, MCP, and Coder interfaces use the shared paging reader. Coder status
  exposes the CLI command; oversized closeouts provide paging metadata instead
  of failing as oversized inline content.
- Always-on handoff packet bounds remain unchanged at 128,000 bytes per source
  and 512,000 bytes aggregate.

## 4. Architecture / Integration Notes

The new document reader is separate from historical-document retrieval and
always-on handoff generation. It resolves only the selected milestone's
canonical closeout or evidence paths explicitly named in the active prompt;
it does not grant arbitrary repository-file access. The HTTP route, MCP tool,
and Coder CLI share the same validation, paging, and source-fingerprint
behavior.

Git staging executes verified bounded batches and reports partial progress
because multiple Git commands cannot provide atomicity. Review and commit
preparation retain existing path-token and worktree/index snapshot safeguards.

fixture evidence answered the implementation and acceptance questions without
materially relying on graph results. Graph status was CURRENT; the targeted
references lookup returned NOT_FOUND. A refresh was considered unnecessary
for this work, so none was attempted.
