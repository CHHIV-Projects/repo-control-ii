## 8. Known Limitations

- Initialization supports only an existing mapped regular UTF-8 file without a BOM and within the one-megabyte preparation limit. Missing mappings, unsafe paths, and ambiguous existing marker content require separate review.
- The operator UI follows the existing loopback Product Owner workflow; role attribution is not identity authentication.
- The transaction revalidates and recovers exact known images, but cannot serialize arbitrary external writers that do not cooperate with Repo Control's lock.
- Passing isolated tests does not establish live Photo Organizer deployment, provider-native hook delivery, session identity, or a fresh Codex session's behavior.
