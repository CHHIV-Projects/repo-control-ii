### Cost observation

The corrected pending-marker implementation's synthetic batched 10,000-event run recorded 12,478,215 serialized event bytes, 12,558,351 segment bytes across 161 files, and 51,945,171 index bytes across 12,806 files. Cumulative append time was 90.944 seconds; full audit took 0.935 seconds. At the 10,000-event point, batch latency p50/p95/maximum was 593.04/802.33/962.83 ms. A separate 1,000 single-event transaction run took 86.96 seconds in the earlier fixture observation; these transaction patterns are not directly comparable.

The index footprint is about 4.16 times the serialized event payload, with substantial file/inode and metadata amplification. This synthetic fixture does not establish an acceptable capacity, throughput, or production operating envelope. Lock contention, aggregate bytes read/written, long-horizon orphan growth, ENOSPC behavior, and production rates were not measured. No automatic pruning exists; do not silently delete retained artifacts or infer an accepted total-history limit.
