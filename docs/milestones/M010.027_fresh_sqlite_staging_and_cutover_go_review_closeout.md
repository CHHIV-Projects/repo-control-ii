## 4. Architecture / Integration Notes

The staging backup unit uses `ProtectSystem=strict` and grants write access
only to the approved RepoControl destination subtree. Systemd presents that
destination as a nested mount inside the service namespace. The backup
preflight now checks the unique expected mount identity and, for the nested
destination, checks filesystem, exact CIFS source, and mount root against the
destination's relative child path. The unit sandbox was not widened and NAS
permissions were not changed.

`supported_source_inputs_changed`). Refresh was considered and not attempted
