## 2. Implementation and provider boundary

New `src/repoctl/intelligence/` contains:

- `provider.py`: replaceable provider protocol and fixed external process runner;
- `worker.py`: pinned Graphify bridge and inherited network denial;
- `service.py`: source scope, generation/freshness, build lifecycle, normalized contract and independent bounds;
- `measurements.py`: private bounded use records, optional feedback, comparative tasks and aggregates;
- `client.py`: local Coder transport to the existing loopback service.

The application environment does not import or install Graphify. Graphify owns parsing, construction, symbol resolution, lexical scoring, traversal, reverse impact and path semantics. Repo Control projects/filters native graph records; it does not build a replacement parser, graph traversal engine, clustering implementation or generic query language.

The bridge uses the tested native single-node resolver, match tiers for ambiguity candidates, lexical scoring/seeding, native BFS/traversal view, affected-node helper and shortest-path renderer. Private helper compatibility is version-pinned and exercised by real-engine tests. A file node plus its members must use native file precedence, not be mislabeled as symbol ambiguity; validation caught and corrected this.

Generic path interior remains native text. Only known success/no-path/hop-limit prefixes are normalized after both endpoints are resolved. No broad NODE/EDGE/path text parser was added. Structured path counts cover endpoints only; interior is not represented as structured edges. Path depth is additionally limited by node/edge capacity. Generic paths may traverse containment and are explicitly **not call chains**.

No initial operation was held back entirely. Structured path-interior arrays, community claims, viewer, semantic/model and PR/network operations are not exposed.

The dedicated input manifest is `tools/graphify-requirements.txt`, separate from application dependencies. Installation report, log and resolved versions are retained beside the environment. This is a Graphify version pin plus recorded dependency resolution, not a separately verified offline-reinstall lock. Runtime directory regular-file content measured 262,447,274 bytes, including installation evidence.

The retained Copilot POC environment is not used as infrastructure. Application Graphify import remains absent. No `graphify install`, hooks, cloud, semantic processing, model credentials, new HTTP listener, new externally exposed service or systemd unit was added.

Each engine request uses a short-lived child with a fixed executable/argument vector and bounded JSON stdin. Its environment is constructed afresh: isolated HOME/XDG/cache/temp, fixed PATH, `GRAPHIFY_NO_AUTO_REFRESH=1`, disabled query logs and bytecode, fixed worker/thread options, and no inherited provider credentials.

Linux `libseccomp.so.2` installs fail-closed denial of socket/connect/bind/listen/accept/accept4/io_uring setup before Graphify imports. The filter is inherited by descendants. Real self-tests verified denied sockets in parent and child. This is **not a general filesystem sandbox**.

The runner independently caps stdout/stderr, applies wall-time termination to the child process group, closes pipes and waits for termination. Worker address-space/CPU/file-size limits are per process, not an aggregate process-tree memory guarantee.

## 4. Source identity, artifact placement and freshness

Intelligence state:

```text
/home/chuck/.local/share/repoctl/intelligence/repo-control-ii--945e7f88eafb
```

The general layout is `<state_root>/intelligence/<repository_id>`, deliberately separate from scanner-republished `<state_root>/<repository_id>` artifacts. Initial validation exposed the scanner publication interaction; moving the namespace and adding a scan-publication regression test resolved it without changing scanner behavior.

Eligible tracked and nonignored untracked code is enumerated with bounded read-only Git listing. Explicit suffixes cover Python/JS and other listed code extensions; HTML/Jinja/CSS are outside this subset. `.git`, virtual environments, dependencies and common generated directories are excluded. Symlinked path components, nonregular files, oversized files/scope and in-repository state roots are rejected.

Scope limits: 10,000 files, 64 MiB aggregate, 2 MiB per file. Source identity hashes actual eligible file bytes and paths, with scope/exclusions/options, branch and HEAD context. Deletions change identity. Documentation/workflow/analytics writes do not spuriously invalidate code evidence.

An explicit build lock publishes BUILDING, copies the scope to an external disposable source directory, runs a full code-only extract, validates producer/schema/hash and checks source identity again. Concurrent edits yield STALE, not false CURRENT. Failures publish FAILED; interrupted BUILDING is diagnosed as FAILED once its lock is no longer held. No silent old-generation fallback occurs. Source copies are removed, and at most current/previous generation directories remain after builds.

States are **MISSING, BUILDING, CURRENT, STALE, FAILED, INCOMPATIBLE**. Only CURRENT graphs supply query evidence. Graph file existence alone is insufficient: generation, producer/schema, options, source identity and artifact hash are checked. Source/generation is checked again after native execution.

The Architect uses `GET /api/architect/v1/intelligence`. Coder uses `repoctl coder-intelligence`, through `GET /api/coder/v1/intelligence` on the same existing service. ## 6. Evidence/error contract and bounds

Shared compact JSON includes repository/generation, graph state/source identity, normalized operation arguments, explicit outcome, source-cited nodes/relationships where available, direction/confidence, returned/omitted counts, impact candidate counts, truncation and limitations. Missing locations remain missing rather than fabricated.

Outcomes include OK, AMBIGUOUS, NOT_FOUND, STALE, FAILED, TRUNCATED and INCONCLUSIVE. Graphify MCP `isError=false` is never used as a success criterion: the bridge returns typed outcomes, native process failures fail explicitly, and only the narrow tested path prefix contract remains textual. Architect MCP marks unsuccessful normalized outcomes as errors while preserving their envelopes.

| Limit | Default | Maximum |
|---|---:|---:|
| Normalized JSON evidence bytes | 49,152 | 65,536 |
| Nodes | 60 | 120 |
| Relationships / impact provenance records | 120 | 240 |
| Traversal depth / path hops | 2 | 4 |
| Query budget, seconds | 5 | 10 |

Minimum byte budget is 4,096. Both consumers use the same compact evidence representation; limits exclude CLI newline and MCP protocol framing. Native stdout is separately capped at 2 MiB, stderr at 64 KiB, graph at 24 MiB, and build process time at 90 seconds. Overflow/timeouts terminate the engine process group, never quietly accept a partial native result as success.

The service budgets native time after source validation and checks the overall query budget. Filesystem/Git and measurement-persistence overhead can extend observed end-to-end wall time; this is not a hard real-time filesystem/I/O guarantee.

Final broad depth-4 query with a 4,096-byte budget returned **3,822 bytes**, outcome TRUNCATED, 21 nodes, 458 omitted nodes and 2,249 omitted relationships. Returned edge count was zero after byte-budget pruning; omission remained explicit.
