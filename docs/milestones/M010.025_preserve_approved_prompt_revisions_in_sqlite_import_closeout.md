## 4. Architecture / Integration Notes

The existing managed confirmation API already performs the required
transactional check against the imported document, revision, source bytes,
digest, repository, and milestone. It records a new candidate-local
Product Owner decision and updates the approved and selected revision pointers
without altering the historical workflow event stream. No weaker import
heuristic is appropriate for the old M010.024 event.

**Repository Intelligence: USED** — the CURRENT graph's caller queries
identified the managed-import entry point and the managed selected-prompt
consumer relationships. These structural results guided source inspection;
the importer/CLI tests and disposable runtime exercised behavior directly.
Graph status was CURRENT when queried and became STALE after supported test and
documentation inputs changed. Refresh was considered and not attempted because
there were no production-source edits and refreshed structure would not
materially improve validation. The two materially useful query results were
rated USEFUL; a refresh receipt was not counted as a query.
